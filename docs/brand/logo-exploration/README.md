# MusicDan Logo 第一轮提案

打开 `index.html` 比较六款设计，可切换深浅背景、单色并下载 SVG。独立设计稿不改动应用或官网。

优先推荐 **01 共鸣音符**：评论气泡与音符一体化，兼顾音乐与弹幕的产品定位。02 更强调节拍；04 最简洁。

所有 SVG 使用 `viewBox="0 0 100 100"` 与 `currentColor`，默认显示黑色，嵌入时可由父元素设置颜色。

展示页参考 logo-generator 的 showcase_template.html 网格与设计说明结构，改为离线可用的原生 HTML，不依赖 CDN。

本轮为概念选择；确认方向后进一步精修边缘、光学尺寸及 Android 自适应图标。
